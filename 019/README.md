# 019-超市管理系统

> POS收银 + 会员管理 + 库存管理 + 进销存一体化平台

## 📋 功能概述

### 1. 数据概览
- 今日销售额统计
- 订单数量统计
- 客单价分析
- 会员占比统计
- 销售趋势图表（折线图）
- 商品分类占比（饼图）

### 2. POS收银台 ✨
专业的POS收银系统，支持以下功能：

#### 商品管理
- **条码/名称搜索**：支持输入条码或商品名称快速搜索
- **快捷商品面板**：8个常用商品快捷按钮，一键添加
- **商品加购**：从商品列表直接添加到购物车

#### 购物车操作
- **数量调整**：支持增加/减少商品数量
- **删除商品**：从购物车移除商品
- **清空购物车**：一键清空所有商品
- **实时金额计算**：自动计算商品总价

#### 会员系统
- **会员登录**：输入手机号快速登录
- **会员等级折扣**：
  - 钻石会员：88折
  - 黄金会员：92折
  - 白银会员：95折
  - 普通会员：98折
- **积分抵扣**：100积分 = ¥1
- **余额支付**：支持使用会员余额支付

#### 支付方式
- 微信支付
- 支付宝
- 现金支付
- 银行卡支付

#### 收银小票
- 完整的交易明细
- 商品清单
- 优惠金额
- 实收金额
- 支付方式
- 打印功能

#### 挂单功能
- 支持暂存当前订单
- F9快捷键挂单

### 3. 商品管理
- 商品列表展示（ID、条码、名称、分类、价格、库存、状态）
- 库存预警标识
- 商品编辑功能
- 快速加购到收银台

### 4. 会员管理
- 会员列表（ID、姓名、手机号、等级、积分、余额、消费总额、注册日期）
- 会员等级标识（钻石/黄金/白银/普通）
- 会员详情查看
- 会员充值功能

### 5. 供应商管理
- 供应商列表（ID、名称、联系人、电话、分类、商品数、最后供货日期）
- 供应商详情查看
- 发起采购功能

### 6. 销售订单
- 订单列表（订单号、时间、商品数、金额、支付方式、收银员、会员）
- 订单详情查看
- 退款功能（预留）

### 7. 库存盘点
- 库存预警列表
- 库存流水记录
- 盘点功能

## 🏗️ 技术架构

基于 **007-库存管理系统** 架构扩展：

- **前端框架**：Bootstrap 5.3 + 原生 JavaScript
- **图表库**：Chart.js 4.4
- **主题风格**：浅色玻璃拟态主题
- **响应式设计**：支持PC端和移动端

## 📊 数据模型

### 商品 (Products)
- id: 商品ID
- name: 商品名称
- barcode: 条码
- category: 分类
- price: 售价
- cost: 成本价
- stock: 库存数量
- unit: 单位
- minStock: 最低库存预警
- status: 状态（正常/库存预警/已缺货）

### 会员 (Members)
- id: 会员ID
- name: 姓名
- phone: 手机号
- level: 会员等级
- discount: 折扣率
- points: 积分
- balance: 余额
- totalSpent: 累计消费
- joinDate: 注册日期
- status: 状态

### 供应商 (Suppliers)
- id: 供应商ID
- name: 供应商名称
- contact: 联系人
- phone: 联系电话
- category: 供货类别
- products: 商品数量
- lastOrder: 最后供货日期
- status: 状态

### 订单 (Orders)
- id: 订单号
- time: 下单时间
- items: 商品数量
- total: 订单金额
- payment: 支付方式
- cashier: 收银员
- member: 会员名称

## 🎯 核心特色

1. **专业POS体验**：模拟真实收银台操作流程
2. **完整会员体系**：四级会员折扣 + 积分 + 余额
3. **库存实时校验**：防止超卖，库存不足预警
4. **快捷操作**：快捷键支持，提高收银效率
5. **数据可视化**：销售趋势、分类占比图表
6. **玻璃拟态设计**：现代化UI设计风格

## 🚀 使用说明

1. 打开 `index.html` 进入项目首页
2. 点击 "019-超市管理系统" 的PC管理后台链接
3. 进入系统后默认显示数据概览
4. 点击左侧导航栏 "收银台" 进入POS收银界面
5. 扫描/搜索商品 → 添加到购物车 → 选择会员 → 选择支付方式 → 完成结算

## ✨ 快捷键

- `F9`：挂单
- `Enter`：搜索商品（搜索框内）
- `+/-`：调整购物车商品数量

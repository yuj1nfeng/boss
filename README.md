# 大规模水产养殖智能化管理系统 - 交互原型

## 📋 项目概述

这是一个完整可交互的H5原型，展示了大规模水产养殖智能化管理系统的核心功能模块。原型采用现代化设计风格，包含完整的数据可视化和交互效果。

## 🎯 功能模块

### 1. 数据概览 (Dashboard)
- **核心指标卡片**：养殖塘口数量、在线设备数、养殖总量、待处理告警
- **水质趋势图表**：近30天溶解氧、水温、pH值变化曲线
- **实时告警列表**：显示最新的异常告警信息
- **塘口状态网格**：8个养殖塘口的实时数据展示

### 2. 水质监测 (Water Quality)
- **塘口选择器**：切换查看不同塘口数据
- **仪表盘可视化**：溶解氧、pH值、水温、氨氮四项核心指标
- **实时数据曲线**：动态更新的实时数据图表
- **指标详情表格**：详细水质参数及状态

### 3. 养殖管理 (Breeding Management)
- **批次管理表格**：养殖批次信息，包含存活率、养殖天数等
- **生长周期追踪**：时间线展示鱼苗投放→鱼苗期→成鱼养殖→收获上市
- **品种分布图表**：饼图展示各养殖品种占比

### 4. 饲料管理 (Feed Management)
- **投喂统计**：今日投喂量、本月累计、饲料库存
- **智能投喂计划**：可开关的定时投喂任务
- **投喂趋势图表**：近一周投喂量柱状图

### 5. 疫病防控 (Disease Prevention)
- **AI智能诊断**：上传病害图片，模拟AI识别分析
- **病害预警**：基于水质数据的病害风险评估
- **防疫记录**：历史防疫措施记录表格

### 6. 设备管理 (Devices)
- **设备概览**：水质传感器、增氧机、投饵机、摄像头统计
- **设备列表**：完整设备信息，包含状态、最后通讯时间
- **设备控制**：远程设备操作入口

### 7. 数据分析 (Analytics)
- **产量预测**：实际产量与预测产量对比曲线
- **成本收益分析**：各项成本柱状图对比
- **关键指标对比**：饵料系数、存活率、人工成本、能耗改善数据

### 8. 系统设置 (Settings)
- **告警阈值设置**：溶解氧、pH值、温度、氨氮告警阈值配置
- **通知设置**：短信、微信、邮件、语音呼叫开关配置

## ✨ 交互特性

1. **实时数据更新**：水质数据每2秒自动刷新，模拟真实IoT数据流
2. **响应式布局**：支持桌面端和移动端自适应显示
3. **平滑动画**：页面切换、数据变化均有流畅过渡动画
4. **模态弹窗**：新增塘口、新增批次等操作弹窗
5. **告警处理**：点击处理按钮可移除告警
6. **开关控制**：投喂计划开关、通知设置开关等交互控件

## 🚀 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 使用左侧导航菜单切换不同功能模块
3. 点击塘口卡片可快速跳转到该塘口的水质监测页面
4. 在水质监测页面使用下拉选择器切换不同塘口
5. 尝试点击各类按钮、开关，体验交互效果

## 🛠️ 技术栈

- **HTML5**：页面结构
- **CSS3**：样式和动画
- **Bootstrap 5.3**：UI框架和响应式布局
- **Chart.js 4.4**：数据可视化图表
- **JavaScript ES6+**：交互逻辑

## 🎨 设计特点

- **深色主题**：科技感蓝紫色渐变配色
- **玻璃拟态**：半透明卡片效果
- **圆角设计**：15px圆角，现代简约风格
- **数据可视化**：仪表盘、折线图、柱状图、饼图
- **状态标识**：正常(绿)、警告(黄)、危险(红)三色状态系统
